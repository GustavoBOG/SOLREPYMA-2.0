# SOLREPYMA 2.0 | Identidad Industrial

![Solrepyma Identity](public/herobg.png)

## 🛠️ Sobre el Proyecto

**SOLREPYMA 2.0** es un estudio integral de identidad corporativa y estrategia de marca para **Solrepyma**, una empresa líder en mantenimiento industrial pesado y soldadura de alta presión con más de 30 años de trayectoria.

Este proyecto web actúa como un manual de marca interactivo y una vitrina de aplicaciones visuales, modernizando el legado de la empresa sin perder la robustez que la caracteriza.

## 🎨 ADN Visual

La nueva identidad se basa en tres pilares fundamentales:

1.  **Potencia:** Representada a través de formas geométricas y el uso del piñón industrial en el logotipo.
2.  **Precisión:** Reflejada en la tipografía técnica y la composición limpia de los documentos operativos.
3.  **Seguridad:** Transmitida mediante una paleta de colores contrastada y altamente visible en entornos industriales.

### Sistema de Diseño

- **Tipografía:**
  - `Roboto` para títulos y rotulación industrial.
  - `Space Grotesk` para textos de cuerpo y datos técnicos.
- **Paleta de Colores:**
  - `Azul Carbón (#0D364E)` - Color primario.
  - `Azul Acero (#3075B6)` - Acento tecnológico.
  - `Blanco (#FFFFFF)` y `Negro (#000000)` - Contraste y legibilidad.

## 🚀 Tecnologías Utilizadas

- **React 19:** Biblioteca base para la interfaz.
- **Vite:** Herramienta de construcción ultrarrápida.
- **Tailwind CSS 4:** Framework de estilos utilitarios modernos.
- **React Icons:** Set de iconos industriales para la interfaz.

## 💻 Instalación y Desarrollo

Para ejecutar este proyecto de forma local, sigue estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/GustavoBOG/SOLREPYMA-2.0.git
    ```
2.  **Instalar dependencias:**
    ```bash
    npm install
    ```
3.  **Iniciar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
